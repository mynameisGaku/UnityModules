# 変更履歴

## [1.1.0] - 2026-08-31

- 製品表示名を「実行中調整」とし、メニュー、画面、状態、結果、失敗理由を日本語で表示するようにしました。
- 未知の列挙値では数値を残し、問題の値を判別できるようにしました。
- 予期しない例外の詳細をコンソールへ記録し、利用者向け表示には内部情報を混ぜないようにしました。
- 調整データの保存失敗を`SessionStorageFailed`として返し、再生状態の更新だけを安全に再試行するようにしました。反映確定前には無効な安全状態を保存し、結果を二度続けて保存できない場合も古い成功表示を残さないようにしました。
- 成功した反映を一つの取り消し履歴として元へ戻せるようにしました。
- 選択対象があるシーンの全階層を検査し、別コンポーネントへ生じたシリアル化値の副作用を検出して失敗時に戻せるようにしました。
- オブジェクトやコンポーネントの追加・削除など、検出できても自動復元を保証しない構造変更を明記しました。
- 選択対象のない別シーン、プロジェクト資産、シーン階層外設定を保証範囲から除き、全階層走査の負荷と復元後の検証範囲を明記しました。
- 公開型、公開列挙値、公開プロパティ、公開関数の役割と失敗条件を日本語で記載しました。
- 編集用試験を`Tests/Editor`と`PlayModeTuning.Editor.Tests`へ整理しました。
- 利用者向け文書、配布情報、実画面画像を日本語表示に合わせました。

## [1.0.0] - 2026-08-23

- 再生モード中に選択項目だけを手動で記録するエディター専用の操作手順を追加しました。
- 通常の`Domain Reload`と`Disable Domain Reload`をまたぐ`SessionState`保持を追加しました。
- `GlobalObjectId`、シーン、`MonoScript`、型、項目を組み合わせた厳密な識別確認を追加しました。
- 文字列を含む最上位の値の許可一覧と、件数・文字列・符号化値の上限を追加しました。
- 単回使用の差分表示、反映直前の古さ確認、反映後確認、シーンの明示的な変更済み化を追加しました。
- 正確な符号化値からの往復変換表示と、解決済み対象名による差分表示を追加しました。
- 未選択項目の副作用検出と、選択項目の復元・復元後確認を追加しました。
- ①から⑤まで上から進める専用画面と、中核契約を固定する編集モード試験を追加しました。
