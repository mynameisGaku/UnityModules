# 利用条件

## Unity Asset Store から取得したパッケージ

Unity Asset Store から取得した Inspector には、取得時点の Unity Asset Store 標準エンドユーザーライセンス契約（EULA）が適用されます。適用条件は Unity Asset Store の商品ページ、取得した Unity アカウントの権利、ならびに次の公式規約を確認してください。

https://unity.com/legal/as-terms

## Git URL / UPM / リポジトリから取得したパッケージ

リポジトリや Git URL からファイルを取得できること自体は、利用、再配布、再許諾その他の権利を新たに付与するものではありません。この経路は、Unity Asset Store の有効な利用権または公開者から別途明示された許諾を持つ利用者が、対応するパッケージ版を取得するための技術的な配布経路です。

別の利用条件が明示されていない場合は、リポジトリの公開状態だけを根拠に利用権が付与されたものとして扱わないでください。
