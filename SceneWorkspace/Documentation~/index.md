# シーン作業セット 1.1.0

## 目的

通常のUnityエディターでは、作業内容を切り替えるたびに複数シーンを開閉し、順番、読込状態、使用中のシーンを手動で戻す必要があります。操作数が多いだけでなく、閉じるシーンや使用中のシーンを取り違える余地があります。

シーン作業セットは、この一連の操作を一つの「シーン構成切り替え」として扱います。設定、差分確認、内容確認、切り替え、結果確認を①から⑤まで上から順に進めます。

## 操作順

1. ①「作業セットを選ぶ」で設定アセットを選びます。
2. ②「シーン構成を設定」で順番、読込状態、使用中のシーンを設定します。
3. ③「差分を確認」で現在構成からの変更を確認します。
4. ④「内容を確認」で閉じるシーンを含む全差分へ同意します。
5. ⑤「作業セットを切り替える」で同じ計画を一度だけ適用します。

![シーン作業セットの操作ガイド](scene-workspace-guide.png)

幅640画素でも同じ順序を維持し、横方向へはみ出しません。最小の640×560画素では縦にスクロールして①と⑤へ到達します。

## 責務の境界

### このモジュールが所有するもの

- `SceneWorkspaceProfile`に保存するシーンの順番、読込状態、使用中状態
- 現在のエディターのシーン構成の読み取り
- 設定との差分計算
- 確認済み計画の単回使用と古さの判定
- `EditorSceneManager.RestoreSceneManagerSetup`を使う切り替え
- 切り替え後の再取得と完全一致確認
- 途中失敗時の元構成への復元試行
- 現在構成を設定へ取り込む操作の「元に戻す」履歴

### 所有しないもの

- シーン内のゲームオブジェクトやコンポーネントの内容
- シーンアセットの保存、変更破棄、削除
- 実行時のシーン読み込み
- ビルド設定、ビルドプロファイル、プレイヤー設定
- 他モジュールの登録情報や設定

実行時アセンブリはありません。エディター用アセンブリだけなので、MonoとIL2CPPのプレイヤー出力および実行時挙動には影響しません。

## ①から⑤までの操作

### ①「作業セットを選ぶ」

プロジェクト内の`SceneWorkspaceProfile`を選びます。新規作成する場合も`Assets`フォルダー以下へ保存します。保存されていない一時オブジェクトは差分確認に使えません。

### ②「シーン構成を設定」

「順序付きシーン構成」の上から下が切り替え後の順番です。各項目には次を設定します。

- 「シーン」: `Assets`フォルダー以下の`.unity`アセット
- 「読み込む」: 切り替え後に読み込むか
- 「使用中にする」: 切り替え後に使用中のシーンとするか

読み込むシーンは最低一つ、使用中にするシーンはその中から正確に一つ必要です。

「現在の構成を設定へ取り込む」は、現在の有効な構成を同じ順番で設定へ複製します。すべてのシーン参照を取得できた後に一括置換するため、途中までの設定は残しません。設定アセットを変更済みにしますが、自動保存しません。取り込み直後はUnityの「元に戻す」で以前の項目へ戻せます。

### ③「差分を確認」

差分確認ではシーン構成を変更しません。最初に現在にだけ存在するシーンの「閉じる」を現在順で返し、続いて設定の各シーンを設定順で処理します。

- 設定に新しく加わるシーンは「開く」、必要なら続けて「使用中にする」
- 現在にもあるシーンは「読み込む」または「読み込みを解除する」、「並べ替える」、「使用中にする」または「使用中を解除する」の順
- 現在にもあり、どの状態も変わらないシーンは「変更なし」

一つのシーンに複数の違いがある場合は複数行で表示します。内部位置は零始まりですが、画面上では「1番」から始めます。未知の差分種別は既知の値へ置換せず、数値付きの「不明な変更」として表示します。

### ④「内容を確認」

差分確認に成功した計画だけを確認できます。確認後に画面内の設定を変更すると、計画と確認欄を破棄します。画面外から設定が変わった場合も、切り替え直前の再比較で停止します。

### ⑤「作業セットを切り替える」

計画は一度だけ適用できます。切り替え直前に現在構成と設定を再取得し、差分確認時の指紋値と一致することを確認します。

一致した場合だけ設定の構成へ切り替えます。その後に再取得し、次を完全一致で確認します。

- シーン数
- 配列順
- GUIDとパス
- 読込状態
- 使用中状態
- 未保存の変更がないこと

一致しない場合や予期しない例外が発生した場合は、差分確認時の元構成への復元を一度試み、復元後も同じ項目を確認します。予期しない例外の詳細はコンソールだけへ記録し、画面には日本語の一般案内を表示します。

切り替え操作そのものはUnityの「元に戻す」履歴へ登録しません。失敗時の自動復元と、②の取り込み操作に対する「元に戻す」は別の仕組みです。

## 切り替えと復元の結果

`SceneWorkspaceApplyResult`は次を別々に持ちます。

- `ApplyAttempted` / `ApplySucceeded` / `ApplyError` / `ApplyMessage`: 切り替え結果
- `RollbackAttempted` / `RollbackSucceeded` / `RollbackError` / `RollbackMessage`: 元構成への復元結果

切り替え失敗後に復元が成功しても、元の切り替え失敗は成功扱いに変えません。復元が失敗した場合は`RollbackFailed`を別に返します。

切り替え前の再確認で停止した場合は`ApplyAttempted`が`false`で、復元は不要です。

## 指紋値

現在構成の指紋値には、順番、シーンGUID、パス、存在状態、読込状態、使用中状態、未保存状態を長さ付きで連結し、SHA-256で記録します。

設定の改訂指紋には、設定GUID、パス、名前と、順番付きのシーンGUID、パス、存在状態、読込状態、使用中状態を記録します。シーンアセット内部のゲームオブジェクト内容はこのモジュールの責務外なので含めません。

計画の世代管理はエディター領域内の最大64件です。上限を超えた古い計画、領域再読込前の計画、別オブジェクトへ複製された計画は`StalePlan`として拒否します。使用済みの同一計画は`PlanAlreadyConsumed`です。

## 失敗条件

| 列挙値 | 停止する条件 | シーン変更 |
| --- | --- | --- |
| `InvalidProfile` | 設定未選択 | なし |
| `ProfileNotSaved` | 設定が`Assets`フォルダー以下のアセットではない | なし |
| `NoScenes` | 現在構成または設定が空 | なし |
| `MissingScene` | シーンアセットまたはGUIDが欠損 | なし |
| `DuplicateScene` | GUIDまたはパスが重複 | なし |
| `UntitledScene` | 保存されていないシーンが開いている | なし |
| `DirtyScene` | 未保存変更を持つシーンがある | なし |
| `UnsupportedScenePath` | `Assets`フォルダー以下の`.unity`ではない | なし |
| `NoLoadedScene` | 読み込むシーンが0件 | なし |
| `InvalidActiveScene` | 使用中にするシーンが一つではない、または読み込まない設定 | なし |
| `PlayModeActive` | 再生モード中または切り替え中 | なし |
| `EditorBusy` | コンパイル中またはアセット更新中 | なし |
| `PrefabStageOpen` | プレハブ編集画面を開いている | なし |
| `StalePlan` | 現在構成、設定、世代、オブジェクト同一性が一致しない | なし |
| `PlanAlreadyConsumed` | 同じ計画を再使用 | なし |
| `ApplyInProgress` | 別の切り替え処理が実行中 | なし |
| `CaptureFailed` | 構成取得中に処理できない問題が発生 | なし |
| `ApplyFailed` | Unityの構成復元呼び出しが失敗 | 部分変更の可能性があるため復元 |
| `VerificationFailed` | 切り替え後の再取得が不一致 | 復元 |
| `RollbackFailed` | 元構成の復元または確認に失敗 | 自動処理を終了 |

未知の列挙値は成功扱いにせず、数値付きの「不明な問題」として表示します。

## 公開API

### `SceneWorkspaceService.CaptureCurrentSetup()`

現在構成を検査して`SceneWorkspaceCaptureResult`を返します。シーン変更は行いません。

### `SceneWorkspaceService.Preview(SceneWorkspaceProfile)`

現在構成と設定を取得し、`SceneWorkspacePlan`を返します。成功した計画には世代番号、設定の改訂指紋、現在構成の指紋値、現在・目標シーン、差分が含まれます。

### `SceneWorkspaceService.Apply(SceneWorkspacePlan)`

計画を単回消費し、再確認、切り替え、切り替え後確認を行います。必要な場合だけ元構成への復元を試みます。`Preview`が返した同一の計画オブジェクトが必要です。

公開データ型の一覧は読み取り専用の複製です。設定はインスペクターと専用画面から明示的に編集する`ScriptableObject`であり、計画から直接参照しません。

## 検証方針

- 計画処理をUnity APIから分離し、同じ状態記録から同じ差分順を返すことを確認する。
- 使用中のシーンを既存シーン間で移す場合に、解除側と設定側の両方を表示する。
- 再生、コンパイル、更新、プレハブ編集、未保存、無題、欠損、重複、読込なし、使用中指定不正で復元処理を一度も呼ばないことを確認する。
- 差分確認後の現在構成と設定の改訂指紋の変化を別々に確認する。
- 同一計画の再使用、同じ世代を持つ別オブジェクト、64件を超えた古い計画を拒否する。
- 切り替え例外と切り替え後不一致の両方で元構成を復元し、再確認する。
- 復元の成功と失敗を切り替え結果から独立して確認する。
- 現在構成の取り込みが自動保存されず、「元に戻す」で旧設定へ戻ることを実シーンアセットで確認する。
- 見出しが①、②、③、④、⑤の順で、設定の後に差分確認、最後に切り替えがあることを固定する。
- Unity 6000.5.7f1の実画面で840×780、640×780、最小640×560の上端・下端を確認し、横切れ、重なり、到達不能な操作がないことを確認する。
