# ビルドガード基本例

## 1. 正常な手動検査とビルドを確認する

1. `BuildGuardBasics.unity`を開きます。
2. Build Profilesのシーン一覧へ追加し、このシーン1件だけを有効にします。
3. **Tools > ビルドガード > ビルド対象シーンを検査** を開き、`ビルド対象シーンを検査`を押します。
4. `シーンを1件検査しました。欠落参照は見つかりませんでした。`を確認します。
5. プレイヤービルドを実行します。

このシーンは有効な根元と無効な子を持ちますが、壊れた参照はありません。Build Guardはビルドを止めません。

## 2. ビルド対象外の選択シーンを確認する

1. `BuildGuardBasics.unity`を`BuildGuardSelectedScene.unity`として複製します。
2. 複製したシーンをBuild Profilesへ追加せず、プロジェクトウィンドウで直接選択します。
3. 右クリックして **ビルドガード > 選択シーンを検査** を選びます。
4. `記録済みの選択シーン`が`1件`であることを確認し、`選択シーンを検査`を押します。
5. `選択シーンを1件検査しました。欠落参照は見つかりませんでした。`を確認します。
6. 確認後は複製したシーンを削除します。

選択シーンの検査はBuild Profileへの登録や有効状態に関係なく使えます。フォルダーを再帰せず、直接選択した`Assets/`配下の保存済みシーンだけを検査します。

## 3. 欠落スクリプトを安全に確認する

`BrokenSceneExample.unity.txt`は欠落スクリプトを1件持つシーンYAMLです。`.txt`なのでサンプルを取り込んだだけではシーンとして読み込まれません。

1. 作業用ブランチか使い捨てプロジェクトでひな形を複製します。
2. 複製先の拡張子を`.unity`へ変更します。
3. そのシーンだけをプレイヤービルド対象へ指定します。
4. 手動検査に`Broken Example[0]`と`欠落スクリプト: 1`が出ることを確認します。
5. `開いて除去`を押し、対象ゲームオブジェクトから欠落スクリプトが除去されることを確認します。
6. シーンが未保存のまま残ることを確認し、元に戻す操作で欠落スクリプトが戻ることも確認します。
7. 再度除去してシーンを保存すると、手動検査とプレイヤービルドが欠落スクリプトでは止まらなくなることを確認します。
8. 確認後は複製したシーンを削除します。

## 4. 欠落オブジェクト参照を確認する

この手順も作業用の複製で行ってください。

1. `BuildGuardBasics.unity`を複製して開きます。
2. カメラを1つ追加します。
3. プロジェクトウィンドウでRender Textureアセットを作成します。
4. Render TextureをカメラのTarget Textureへ設定し、シーンを保存します。
5. Render Textureアセットを削除します。
6. シーンを閉じて開き直し、そのシーンをプレイヤービルド対象へ指定します。
7. 手動検査に`UnityEngine.Camera`と`m_TargetTexture`が出ることを確認します。
8. `シーンを開く`でカメラが選択されることを確認します。
9. プレイヤービルドも同じ問題で止まることを確認します。
10. 確認後は複製したシーンを削除します。

Build Guardは欠落スクリプトだけを明示操作で除去できます。欠落オブジェクト参照の推測修復、シーンの自動保存、アセット削除は行いません。`内容をコピー`で1件の修復情報を共有できます。

## 5. プレハブの欠落スクリプトを確認する

`BrokenPrefabExample.prefab.txt`は欠落スクリプトを1件持つプレハブのYAMLです。`.txt`なので取り込んだだけではプレハブとして読み込まれません。

1. 作業用ブランチか使い捨てプロジェクトでひな形を複製します。
2. 複製先の拡張子を`.prefab`へ変更します。
3. プロジェクトウィンドウでそのプレハブを選択します。
4. 右クリックして **ビルドガード > 選択プレハブを検査** を選びます。
5. `記録済みの選択プレハブ`が`1件`であることを確認し、`選択プレハブを検査`を押します。
6. `BrokenPrefabExample[0]`と`欠落スクリプト: 1`を確認します。
7. `開いて除去`を押し、プレハブモードで欠落スクリプトが除去されることを確認します。
8. プレハブモードの自動保存設定に応じた保存状態を確認し、元に戻す操作で欠落スクリプトが戻ることも確認します。
9. 確認後は複製したプレハブを削除します。

プレハブの検査も欠落オブジェクト参照を表示しますが、参照先は推測しません。`プレハブを開く`で対象ゲームオブジェクトを選択し、インスペクターで該当項目へ正しいアセットを指定してください。`内容をコピー`では1件の修復情報を共有できます。
